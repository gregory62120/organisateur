# Gestion Projet Local

Application Angular de gestion de projet offline.

## Fonctionnalités

- Kanban
- Gantt
- Calendrier
- Documents
- Images
- ZIP Import/Export
- Fonctionnement hors ligne

## Installation

npm install

## Démarrage

ng serve

## Stockage

Les projets sont stockés localement
dans des dossiers transportables.
